# Third-party software

Kivou's application code in app/, desktop/ and core/ is an independent implementation by rayaneDR. It contains no Goose, OpenClaw, Muse or other competitor application source or binary. Public feature documentation and user reports informed the product research, as linked in docs/RESEARCH.md.

The application uses Electron (MIT and its bundled Chromium/Node licenses). Its notices remain in the distributed dependency files. Build and test tooling includes electron-builder and Playwright under their respective licenses. The external Codex CLI is separately installed, licensed and authenticated by the user; it is not included in the portable executable.

This source repository has independent history. The earlier Goose-based Kivou experiment is a separate project; its upstream history and legal notices must remain with that code.
